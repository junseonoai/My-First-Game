# 온라인 원카드

친구들과 방 코드로 모여 함께 하는 멀티플레이 원카드 게임입니다. 사람이 부족하면 봇을 넣을 수 있어요. (2~6명)

## 봇 등급

대기실에서 **봇 추가**를 누르고 등급을 골라요. 방장은 봇마다 등급을 바꿀 수 있어요.

| 등급 | 특징 | 원카드 버튼 |
|---|---|---|
| 실버 | 아무 카드나 내고 가끔 기회를 놓쳐요 | 느리고 자주 깜빡해요 |
| 골드 | 공격 카드부터, 같은 숫자는 몰아서 | 보통 |
| 플래티넘 | 공격 카드·조커를 아꼈다가 받아쳐요 | 빠름 |
| 마스터 | + 나온 카드 기억, 이기기 직전인 사람 견제 | 아주 빠름 |
| 그랜드마스터 | 마스터의 판단 + 거의 놓치지 않는 반응 | 최고 |

모든 봇은 다른 사람 손패를 보지 않아요. 등급별 실험 결과는 `test/TIERS.md`에 있어요.

## 실행 방법

```bash
cd onecard
npm install
npm start
```

브라우저에서 http://localhost:3000 을 열고 **방 만들기** → **코드 복사**로 4자리 방 코드를 친구에게 보내면 됩니다.
같은 와이파이의 친구는 `http://<내 컴퓨터 IP>:3000` 으로 들어올 수 있어요.

인터넷 어디서나 같이 하려면 Node.js 서버를 올릴 수 있는 곳(Render, Railway, Fly.io 등)에 `onecard` 폴더를 배포하세요.
시작 명령은 `npm start`, 포트는 `PORT` 환경변수를 따릅니다.

## 규칙

- 바닥 카드와 **무늬** 또는 **숫자**가 같은 카드를 냅니다. 낼 카드가 없으면 1장 뽑습니다.
- **공격**: 2 → 2장, A → 3장, A♠ → 5장, 흑백 조커 → 5장, 컬러 조커 → 7장
  - 공격 카드(무늬나 숫자가 맞는 것)나 조커로 되받아치면 장수가 쌓입니다. A 공격은 2로도 받아칠 수 있어요.
  - 조커 공격은 조커나 **A♠**로 받아칠 수 있어요.
  - 2나 A 공격은 같은 무늬의 **3**으로 막을 수 있습니다. (공격이 사라짐)
  - 못 막으면 쌓인 장수만큼 먹습니다.
- **같은 숫자 카드는 여러 장을 한 번에** 낼 수 있어요. 첫 장만 낼 수 있으면 되고 효과는 합쳐져요. (2 두 장 → 4장 공격, J 두 장 → 두 명 건너뛰기, Q 두 장 → 방향 그대로) 고른 순서대로 내고 마지막 카드가 바닥 맨 위에 와요.
- **J** 다음 사람 건너뛰기 · **Q** 방향 바꾸기 · **K** 한 번 더 · **7** 무늬 바꾸기
- 둘이 할 때는 **J·Q를 몇 장 내든 다시 내 차례**예요.
- 공격이 아닌 조커 뒤에는 아무 카드나 낼 수 있습니다.
- 누군가 한 장 남으면 모두의 화면에 **원카드!** 버튼이 떠요(스페이스바도 가능). 선착순으로, 본인이 먼저 누르면 안전하고 다른 사람이 먼저 누르면 1장 벌칙!
- 낼 수 있는 카드는 테두리 색으로 구분돼요: 빨강 받아치기 · 노랑 막기 · 무지개 조커 · 흰색 일반
- 내 카드는 **모양순 / 숫자순**으로 정렬할 수 있어요.
- 손패가 **30장 이상**이면 파산(탈락)입니다.
- 손패를 모두 낸 순서대로 순위가 정해지고, 한 명만 남으면 끝납니다.
- 게임 중 😀 버튼으로 빠른 이모티콘과 빠른 채팅을 보낼 수 있어요.
- 원카드: 판이 멈추고 3초 카운트다운 → 버튼이 열리면 2초 안에 누르기 → 누르면 내 기록이 바로 나와요 → 모두 눌렀거나 2초가 지나면 가운데에 전체 결과('원카드 성공!' 또는 '벌칙 1장', 못 누른 사람은 '실패')가 1초쯤 뜬 뒤 모두 동시에 판이 다시 움직여요. 가장 먼저 누른 사람이 승부를 정해요(본인이면 안전, 남이면 1장 벌칙, 아무도 안 누르면 벌칙 없음).
- 위쪽 막대: 왼쪽 나가기(확인 후), 오른쪽 테이블 색·기록. 빠른 채팅·이모티콘만 오른쪽 아래에 있어요.
- 경기 기록과 채팅은 새 판이 시작되면 비워져요.
- 카드가 많으면 손패가 두 줄로 보여요.
- 내 카드는 상자 안에 있고, 내 차례면 상자가 금색으로 바뀌며 위쪽 탭에 남은 초가 크게 나와요(10초부터 빨강).
- 위쪽 팔레트 버튼(또는 시작 화면의 '테이블 색 바꾸기')으로 테이블 색을 초록·남색·와인·나무·차콜 중에서 고를 수 있어요.
- 둘이 할 때는 1등·2등 대신 우승·패배로 표시해요.
- 게임 시작: 단색 배경에서 먼저 할 사람을 골라요(둘이면 **카지노 칩 던지기**, 셋 이상이면 **룰렛**) → 덱이 나타나고 한 사람씩 7장을 나눠 줘요 → 시작 카드 한 장이 바닥에 놓이고 → 누가 먼저인지 알려 주며 시작해요.
- 카드를 받으면 받은 사람 자리에 '+N장'이 크게 떠요. 셋 이상일 때는 가운데에 도는 방향이, 다음 차례인 사람 자리에 '다음' 표시가 나와요.
- 시작 화면의 **튜토리얼**에서 규칙을 문제로 풀어 보고 원카드 버튼을 연습할 수 있어요.
- 내 차례 제한 시간은 30초입니다. 지나면 자동으로 카드를 뽑아요.

## 테스트

```bash
npm test                                # 봇끼리 3000판을 돌려 규칙 엔진을 검사
node test/table.js 3000                 # 등급별로 골드 3명과 붙여 승률 보기
OPP=master node test/table.js 3000 grandmaster   # 상대 등급을 바꿔서
ONECARD_CHECK=1 npm start                # 개발용: 매 수마다 카드 수·차례·원카드 멈춤을 점검해 문제를 로그로 남김
```

## 구조

- `game.js` — 게임 규칙 (서버에서만 실행, 손패는 본인에게만 전송)
- `server.js` — Express + Socket.IO 방/턴/봇 관리
- `bots.js` — 봇 5등급의 판단과 원카드 반응 속도
- `public/` — 브라우저 화면
