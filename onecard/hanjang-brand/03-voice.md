# 말투와 카피

## 한장의 말투

판을 깔아주는 친구처럼 말한다. **존댓말(~요)이 기본**이고, 짧고, 한 문장에 한 가지만 말한다.

| 원칙 | 이렇게 | 이렇게 말고 |
| --- | --- | --- |
| 짧게 | 내 차례예요 | 지금은 회원님의 턴입니다. 카드를 선택해 주십시오 |
| 할 일을 말하기 | 같은 무늬나 숫자를 내 주세요 | 유효하지 않은 카드입니다 |
| 사람을 주어로 | 민지님이 공격했어요 | 공격이 발생했습니다 |
| 놀리되 다정하게 | 30장… 파산이에요. 다음 판은 꼭! | 파산! 꽝! 실패! |
| 하이라이트는 크게, 나머지는 조용히 | **원카드!** | 원카드!!!! 🔥🔥 |

- 느낌표는 하이라이트(원카드!, 승리!, 공격)에만, 한 개만.
- 이모지는 UI 글자에 쓰지 않는다. 초대 메시지·SNS 글에서는 하나까지.
- 숫자는 아라비아 숫자로: "카드 7장", "30초".
- 플레이어는 "닉네임 + 님". 나 자신은 "나" 또는 생략.
- 게임 용어는 원카드에서 원래 쓰는 말 그대로: 공격, 방어, 원카드, 파산, 뽑기. 새 용어를 만들지 않는다.

## 카피 사전: 지금 화면을 이렇게

지금 게임 화면의 문구는 대부분 이미 한장 말투(짧은 ~요체)라 그대로 둔다. 바꿀 것만 적었다.

| 위치 | 지금 | 한장 |
| --- | --- | --- |
| 브라우저 탭 제목 | 온라인 원카드 | 한장: 친구들과 바로 원카드 |
| 로비 제목 | ♥원카드♠ | (로고 가로 조합) |
| 로비 부제 | 친구와 함께하는 온라인 카드 게임 | 링크 하나로 친구들과 바로 원카드 |
| 로비 첫 펼침 | 게임 규칙 목록 (접기) | 그대로 두되 기본은 접힌 상태 |
| 방 코드 칸 | 방 코드 | 그대로 |
| 튜토리얼 버튼 | 튜토리얼 | 그대로 (처음 접속이면 "처음이라면? 규칙 1분 배우기" 한 줄을 위에) |
| 봇 실력 / 테이블 색 바꾸기 | 그대로 | 그대로 |
| 대기실 버튼 | 코드 복사 · 봇 추가 · 게임 시작 · 나가기 · 내보내기 | 그대로. "코드 복사" 옆에 "링크 복사" 추가 권장 |
| 게임 중 안내 | 낼 카드를 고르세요 | 그대로 |
| 방향 표시 | 반시계 방향 | 그대로 |
| 덱 아래 | 남은 카드 9 | 그대로 |
| 정렬 버튼 | 숫자순 | 그대로 |
| 나가기 확인 | 나갈까요? / 계속하기 · 나가기 | 그대로 (주 버튼이 "나가기"라 와인색이 맞음) |
| 메뉴 | 테마 변경 · 기록·채팅 · 설정 | 그대로 |

## 게임 중 문구

| 상황 | 문구 |
| --- | --- |
| 대기실, 혼자 | 친구를 기다리는 중이에요. 방 코드를 보내 주세요 |
| 대기실, 2명 이상 | {n}명 모였어요. 방장이 시작하면 바로 시작! |
| 시작 버튼(방장) | 게임 시작 |
| 내 차례 | 내 차례예요 |
| 남의 차례 | {이름}님 차례 |
| 낼 수 없는 카드를 누름 | 같은 무늬나 같은 숫자만 낼 수 있어요 |
| 시간 초과 | 시간이 다 돼서 한 장 뽑았어요 |
| 공격 받음 | 공격 +{n}! 받아치거나, 막거나, {n}장 받기 |
| 받아치기 | 받아쳤어요! 이제 +{n} |
| 막기 (같은 무늬 3) | 막았어요! 공격이 사라졌어요 |
| 누가 한 장 남음 (판 멈춤, 3초 카운트) | {이름}님이 한 장 남았어요 · 3 · 2 · 1 |
| 원카드 버튼 열림 (2초) | 원카드! (버튼) |
| 본인이 먼저 누름 | 원카드! {이름}님 안전 |
| 남이 먼저 누름 | 잡았다! {이름}님 1장 받기 |
| 아무도 안 누름 | 아무도 안 눌렀어요. 그냥 진행해요 |
| 파산 (30장) | 30장… {이름}님 파산이에요 |
| 승리 (나) | 승리! 마지막 한 장까지 내가 이겼어요 |
| 승리 (남) | {이름}님이 이겼어요 |
| 결과 화면 버튼 | 한 판 더 / 로비로 |
| 연결 끊김 (나) | 연결이 끊겼어요. 다시 연결하는 중… |
| 연결 끊김 (남) | {이름}님 연결이 끊겼어요. 1분 기다릴게요 |
| 1분 지나 퇴장 | {이름}님이 나갔어요. 남은 사람끼리 계속해요 |
| 없는 방 코드 | 그런 방이 없어요. 코드를 다시 확인해 주세요 |
| 방이 꽉 참 | 방이 꽉 찼어요. 다른 방을 만들어 보세요 |
| 이미 시작한 방 | 이미 게임 중인 방이에요. 끝나면 들어갈 수 있어요 |

특수 카드는 "{카드} {효과를 동사로}" 형식: "J 건너뛰기", "Q 방향 바꾸기", "K 한 번 더", "7 무늬 바꾸기". 낼 때 카드 아래 뜨는 라벨도 같은 말("반시계 방향", "건너뛰기")을 쓴다.

## 공유·홍보 문구

- **초대 메시지(카톡 등)**: `한장 하자! 방 코드 K7Q2 👉 {링크}`
- **링크 미리보기 제목**: 한장 — 친구들과 바로 원카드
- **링크 미리보기 설명**: 설치 없이, 가입 없이. 방 코드 하나로 시작하는 원카드.
- **SNS 소개**: 마지막 한 장까지. 친구들과 바로 하는 온라인 원카드, 한장.
