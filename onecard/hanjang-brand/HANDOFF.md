# Claude Code 작업 지시서: "온라인 원카드" → "한장" 리브랜딩

> 이 폴더로 작업을 시작할 때는 **PROMPT.md를 가장 먼저 읽고** 그 규칙을 이 문서보다 우선한다.

이 폴더(`hanjang-brand/`)는 한장 브랜드 가이드 전체다. 작업 전에 아래 순서로 읽는다.

1. `README.md` — 브랜드 개요, 색·글꼴·모양 규칙
2. `04-game-screens.md` — 화면별로 무엇을 바꾸고 무엇을 유지하는지 (가장 중요)
3. `03-voice.md` — 바꿀 문구
4. `02-logo.md` — 로고 파일과 쓰는 법
5. `05-implementation.md` — 단계별 적용 방법
6. `tokens.css` — 바로 쓰는 CSS 변수 (`tokens.json`에서 생성)
7. `components/bundle.css` + 각 `components/*/README.md` — 컴포넌트 모양 기준 (`hj-` 클래스)

## 목표

게임의 **기능·로직·배치는 그대로** 두고 겉모습만 한장 브랜드로 바꾼다.

## 바꾸는 것

- 이름: "온라인 원카드" / "♥원카드♠" → "한장" (탭 제목, 로비 로고, 링크 미리보기 메타태그)
- 로고: `assets/Logos/hanjang-lockup.svg` (로비), `favicon.svg` (파비콘), `hanjang-app-icon.svg` (PWA 아이콘)
- 색: 코드에 박힌 hex 값을 `tokens.css` 변수로 교체. 색 자체는 지금과 거의 같다(와인·머스터드·펠트·종이·남색).
- 모양: 패널·버튼의 각진 굵은 검정 테두리와 딱딱한 오프셋 그림자 → 둥근 모서리(`--radius-md`, `--radius-lg`) + `--shadow-card`/`--shadow-lift`
- 글꼴: 제목·큰 숫자(장수, 타이머, 원카드 배너)는 `--font-display`(메이플스토리 Bold), 본문 `--font-sans`, 방 코드 `--font-mono`. 지금의 세리프 숫자는 없앤다.
- 카드 뒷면: 남색 마름모 무늬는 유지하고 가운데에 `hanjang-submark.svg`를 종이색으로 작게.
- 낼 수 있는 카드 테두리: 빨강 받아치기 · 노랑 막기 · 무지개 조커 (지금 규칙 그대로), 선택한 카드는 잉크색 테두리.

## 유지하는 것 (건드리지 않는다)

- 게임 규칙과 서버 로직 전부
- 칩 던지기·룰렛 연출 (색만 토큰으로)
- 클래식 J·Q·K 그림 카드 이미지
- 빠른 채팅·이모지 반응, 봇 등급, 테이블 색 5종, 튜토리얼 9단계, 메뉴(테마 변경·기록·채팅·설정)
- '진동', '애니메이션 줄이기' 설정 (새 효과도 이 설정을 따른다)

## 작업 순서 (단계마다 커밋)

1. `hanjang-brand/tokens.css`와 `fonts/MaplestoryBold.woff`를 정적 파일 경로에 복사하고 전역으로 불러오기
2. 이름·로고·파비콘·메타태그 교체
3. 하드코딩된 색 → 변수 교체 (`#` 검색)
4. 테두리·그림자 → 둥근 모서리·부드러운 그림자
5. 글꼴 교체
6. 카드 뒷면·카드 테두리 상태 정리
7. `05-implementation.md` 맨 아래 점검표로 확인

## 주의

- 메이플스토리 서체는 넥슨 저작물. 폰트 파일을 수정하지 말고 그대로 쓴다.
- 색만으로 정보를 주지 않는다(차례 표시는 테두리+글자, 등급 배지는 이름 포함).
- 확실하지 않은 디자인 결정은 임의로 정하지 말고 질문한다.
