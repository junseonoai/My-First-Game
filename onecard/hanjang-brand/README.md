# 한장 — 브랜드 가이드

> **마지막 한 장까지.**

**한장**은 친구들과 링크 하나로 바로 시작하는 온라인 원카드 게임이다. (구 이름: "온라인 원카드")

원카드에서 가장 짜릿한 순간은 손에 카드가 딱 **한 장** 남았을 때다. "원카드!"를 외치는 그 순간, 다들 숨을 죽이고, 누군가는 공격 카드를 만지작거린다. 한장은 이 순간을 브랜드의 중심에 둔다. 이름도, 로고("원카드!"를 외치는 말풍선 카드)도, 가장 아끼는 색(콜 옐로)도 전부 그 순간을 위해 있다.

이 문서는 한장을 만드는 모든 사람(개발, 디자인, 홍보 글을 쓰는 사람)이 같은 한장을 만들기 위한 기준이다. 뒤쪽 섹션에 이름 이야기, 로고 규칙, 말투·카피 사전, 게임 화면 적용, 코드 적용 방법이 이어진다.

---

## 1. 한 문장 정의

| 항목 | 내용 |
| --- | --- |
| 무엇 | 설치·가입 없이 방 코드 하나로 친구들과 하는 실시간 원카드 |
| 누구를 위해 | 원카드를 알거나(학교·MT·동아리에서 해본 사람) 처음 배우는 10~30대, 그리고 이들이 부르는 친구들 |
| 왜 한장인가 | 카드 없이도, 같은 자리에 없어도, 30초 안에 한 판을 시작할 수 있다 |
| 약속 | 규칙은 쉽게, 판은 빠르게, 마지막 한 장은 짜릿하게 |

## 2. 브랜드 성격

한장은 **"판 깔아주는 친구"** 같은 브랜드다. 모임에서 카드를 꺼내고, 규칙을 모르는 사람에게 웃으며 알려주고, 진 사람을 놀리되 상처 주지 않는 사람.

| 이런 느낌 | 이런 느낌은 아님 |
| --- | --- |
| 장난스럽고 빠름 | 유치하고 시끄러움 |
| 친절함 (처음 온 사람도 바로 낌) | 설명이 길고 가르치려 듦 |
| 긴장감 있는 하이라이트 | 도박 분위기 (돈, 베팅, 잭팟) |
| 깔끔하고 단단한 화면 | 반짝이 그라데이션, 이모지 범벅 |

**돈이 걸린 것처럼 보이지 않기**는 디자인 원칙이다. 선 정하기 연출(칩 던지기, 룰렛)은 "누가 먼저 할지 정하는 장난감"으로 그대로 쓴다. 하지만 칩에 금액을 쓰거나, 베팅·잭팟·슬롯·현금 같은 말과 이미지는 쓰지 않는다. 칩에는 플레이어 이름만, 룰렛 칸에도 이름만 들어간다. 펠트 초록은 "카지노"가 아니라 "카드놀이 테이블"을 뜻한다.

## 3. 핵심 시각 요소 (요약)

- **로고**: 말풍선 꼬리가 달린 카드(−8° 기울어짐) 안에 한글 ㅎ 모양의 스페이드가 들어간 심볼 + 메이플스토리 Bold로 쓴 "한장" 글자. 파비콘처럼 아주 작은 자리에는 말풍선을 뺀 ㅎ 스페이드(보조 심볼)를 쓴다. 자세한 규칙은 [로고] 섹션.
- **색은 지금 게임의 조합 그대로**: 와인 레드(`brand`), 펠트 초록(`felt`), 머스터드(`call`), 종이 크림(`ground`), 잉크(`ink`), 남색 카드 뒷면(`card-back`). 새 브랜드는 이 색 위에 둥근 모양·메이플스토리 글꼴·말풍선 로고를 얹은 것이다.
- **글꼴**: 로고·제목·외침은 둥글고 통통한 *메이플스토리 Bold*(`display`), 본문은 *Noto Sans KR*(`sans`), 방 코드·타이머 숫자는 *IBM Plex Mono*(`mono`). 메이플스토리는 넥슨 무료 서체(로고·임베딩 사용 가능), 나머지 둘은 Google Fonts.
- **모양**: 카드처럼 둥근 모서리(`radius-md` 12px), 살짝 기울임(로고 −8°, 외침 배너 −3°). 기울임은 "지금 뭔가 일어났다"는 신호라 아껴 쓴다.

## 4. 색

모든 색은 이름(토큰)으로 쓴다. 코드에 `#933231`을 직접 쓰지 말고 `var(--brand)`를 쓴다. 다크 테마는 같은 이름에 다른 값이 들어간다.

### 역할별 사용

| 토큰 | 역할 | 쓰는 곳 | 쓰지 않는 곳 |
| --- | --- | --- | --- |
| `ground` | 종이 크림 | 로비·대기실 패널, 모달, 결과 화면 카드 | 게임판 바탕 |
| `raised` / `sunken` | 떠 있는 면 / 들어간 면 | 패널·모달 / 규칙 목록·입력 바탕 | — |
| `ink` / `ink-muted` | 글자 | 본문·제목 / 설명·캡션 | `felt` 위 |
| `brand` | 와인 레드 | 주 버튼(방 만들기·게임 시작·다음), 로고, 공격, 5초 남은 타이머 | 넓은 배경, 장식 |
| `felt` / `felt-deep` | 테이블 / 패인 자리 | 로비·대기실·게임판 전체 배경 / 상대 자리, 남의 차례 손패 칸 | 버튼 |
| `table-*` | 테이블 색 5종 | 초록·남색·와인·나무·차콜. 사용자가 고르면 `felt` 자리에 들어감 | 그 밖의 곳 |
| `call` / `call-soft` | 머스터드 | 내 차례 손패 칸, "차례" 표시, 막기 카드 테두리, "원카드!", 승리 글자 / 타이머 바 | 크림 위 글자색 |
| `hint-counter` / `hint-block` | 낼 수 있는 이유 | 받아치기(빨강)·막기(노랑) 카드 테두리. 조커는 무지개 | 선택 표시(선택은 잉크 테두리) |
| `card-back` | 남색 | 덱, 상대 손패, 카드 뒷면 | — |
| `tier-*` | 봇 등급 | 실버·골드·플래티넘·마스터·그랜드마스터 배지 | 그 밖의 곳 |
| `focus` | 포커스 링 | 키보드 포커스만 | 장식 |

### 비율

모든 화면의 바탕은 펠트다. 로비·대기실은 **펠트 60 · 종이 패널 35 · 와인 4 · 머스터드 1**, 게임판은 **펠트 65 · 카드 20 · 머스터드(내 차례 손패 칸) 10 · 나머지 5**. 머스터드는 "지금 너 차례야"를 뜻하니 그 밖에 넓게 쓰지 않는다.

### 접근성 (확인 완료)

- 본문 글자(`ink`) 종이 위 14:1, 보조 글자(`ink-muted`) 6.5:1, 펠트 위 글자(`on-felt`) 8.8:1, 머스터드 위 잉크 7.9:1.
- 와인 버튼 위 흰 글자 7.7:1. 다크에서는 와인이 밝아지므로 `on-brand`가 어두운 색으로 바뀐다(6:1).
- 카드 무늬: ♥♦ `suit-red` 6.8:1, ♠♣ `suit-black` 17:1(카드 앞면 위). 봇 등급 배지 글자 4.9:1 이상.
- 색만으로 정보를 주지 않는다: 차례는 테두리 굵기, 공격 카드는 "공격" 글자, 무늬는 모양으로도 구분된다.

| `title` | Noto Sans KR 700 | 22/30 | 모달·섹션 제목 |
| `heading` | Noto Sans KR 700 | 17/24 | 규칙 소제목 |
| `body` / `body-strong` | Noto Sans KR 400/700 | 15/23 | 본문 / 강조·버튼 |

규칙: 메이플스토리는 **짧은 말에만** (10자 이내). 문장을 쓰면 무겁고 읽기 힘들다. 본문에 굵기 2개(400, 700) 이상 섞지 않는다.

## 6. 간격과 모양

- 간격은 4px 단위: `space-1`(4) · `space-2`(8) · `space-3`(12) · `space-4`(16) · `space-6`(24) · `space-8`(32) · `space-12`(48). 이 사이 값(10, 14, 20px…)은 쓰지 않는다.
- 모서리: 배지 `radius-sm` 6 · 버튼·입력·카드 `radius-md` 12 · 패널·게임판 `radius-lg` 20 · 토글·타이머 `radius-pill`.
- 그림자는 둘뿐: 카드가 테이블에 놓인 `shadow-card`, 들어 올린 `shadow-lift`. 패널은 그림자 대신 `raised` 색 차이로 띄운다.
- 터치 대상은 최소 44px 높이(`Button` md).

## 7. 아이콘

`assets/Icons`의 24px 아이콘. 선 아이콘은 1.75px 둥근 선, 무늬 아이콘(♥♦♠♣)은 채움. 모두 `currentColor`라 CSS `color`로 색을 바꾼다. 텍스트 이모지(♥, ♠)를 UI 아이콘으로 쓰지 않는다 — 기기마다 모양과 색이 달라진다.

## 7-1. 이모지

게임 반응용 한장 이모지 10종이 `assets/Emoji/`에 있다. ㅎ 스페이드 캐릭터에 표정을 넣은 것으로, 빠른 채팅의 시스템 이모지를 대신한다. 목록과 쓰임은 `assets/Emoji/README.md`.

## 8. 움직임

- 기본 0.12~0.2초, 끝이 부드러운 ease. 카드 내기·뽑기는 0.25초.
- 큰 움직임은 하이라이트에만: "원카드!" 배너(1.2초), 공격 누적, 승리.
- **'애니메이션 줄이기'가 켜졌거나 기기 설정이 `prefers-reduced-motion`이면** 이동·확대 없이 페이드만. 이 설정은 이미 게임에 있으니 모든 새 효과가 따르게 한다.
- 진동(설정 켬일 때): 내 차례 시작 1회 짧게, 공격 받음 2회, 5초 남음 1회. 그 외엔 진동하지 않는다.

## 9. 절대 하지 않기

1. 로고를 늘리거나, 다시 그리거나, 다른 글꼴로 "한장"을 쳐서 대신하기
2. 돈·베팅·잭팟·슬롯 이미지나 말 (칩·룰렛은 이름만 적힌 선 정하기 장난감으로만)
3. 머스터드를 "내 차례"가 아닌 곳에 넓게 쓰기, 크림 위 글자색으로 쓰기
4. 파랑-보라 그라데이션, 네온, 반짝이 효과
5. 진 사람을 깎아내리는 문구 ("넌 못해", "바보")
6. 규칙 설명을 한 화면에 몰아넣기 — 튜토리얼로 나눠 보여준다

## 10. 이 시스템 쓰는 법 (개발용)

- 색·간격·모서리·그림자는 `tokens.json`의 이름이 곧 CSS 변수 이름이다: `var(--brand)`, `var(--space-4)`, `var(--radius-md)`, `var(--shadow-card)`. 다크 테마는 `<html data-theme="dark">`.
- 글꼴 변수: `var(--font-display)`, `var(--font-sans)`, `var(--font-mono)`. 메이플스토리 파일은 `fonts/MaplestoryBold.woff`(원본 그대로). 넥슨 서체 라이선스: 상업적 사용·로고·임베딩·재배포 가능, 단 글꼴 파일을 수정해서 재배포하거나 글꼴 자체를 판매하는 것은 금지. 저작권은 넥슨코리아.
- 컴포넌트는 `components/bundle.js`가 `window.Hanjang`에 React 18 컴포넌트로 담는다(Button, PlayingCard, RoomCode, PlayerChip, TurnTimer, CallBanner, TextField, Badge, QuickChat). 스타일은 `components/bundle.css`(클래스 접두사 `hj-`). React를 안 쓰는 지금 코드에서는 클래스 이름과 CSS만 가져다 써도 같은 모양이 나온다.
- 로고와 아이콘은 `assets/` 아래 SVG. 컬러 로고(`hanjang-lockup.svg`, `hanjang-symbol.svg`)는 색이 고정이라 `<img>`로 바로 쓴다. `-mono`가 붙은 단색 로고와 보조 심볼은 `currentColor`라 인라인 SVG로 넣고 `color`를 준다.
- 실제 코드에 적용하는 단계별 방법은 **코드 적용** 섹션에 있다.
