# 게임 화면에 적용하기

지금 게임(2026년 11월 화면 기준)의 구조와 색은 그대로 두고, 그 위에 한장의 로고·모양·글꼴을 입힌다. 바꾸는 것은 세 가지뿐이다.

1. **모양**: 각진 굵은 테두리 + 딱딱한 그림자 → 둥근 모서리(`radius-md`·`radius-lg`) + 부드러운 그림자(`shadow-card`·`shadow-lift`).
2. **글꼴**: 세리프 숫자·제목 → 메이플스토리 Bold(`display`). 본문은 Noto Sans KR, 방 코드는 IBM Plex Mono.
3. **로고**: "♥원카드♠" 글자 → 한장 로고.

색(펠트·종이·와인·머스터드·남색), 배치, 기능, 연출(칩 던지기·룰렛)은 그대로다.

## 공통

- 모든 화면의 바탕은 `felt`(사용자가 고른 테이블 색). 지금처럼 은은한 펠트 결 텍스처는 유지해도 된다.
- 패널·모달: `ground` 종이 크림, `radius-lg` 20px, `shadow-lift`. 테두리는 없앤다.
- 버튼: 주 버튼은 `brand` 와인(`Button` primary), 나머지는 `raised` 바탕 + `line-strong` 1.5px 테두리(`Button` secondary). 높이 44px 이상, `radius-md`. 지금의 아래쪽 딱딱한 그림자는 빼고 눌렀을 때 1px 내려가는 움직임만 남긴다.
- 모달이 뜨면 뒤를 `felt-deep` 60% 정도로 어둡게(지금과 같음).

## 로비

지금 배치 그대로: 로고 → 부제 → 닉네임 → 방 만들기 → "또는 코드로 참가" → 방 코드 + 참가 → 튜토리얼 · 봇 실력 → 테이블 색 바꾸기 → 게임 규칙(접힘).

- 맨 위 "♥원카드♠"를 `hanjang-lockup.svg`(높이 40px)로 교체.
- 게임 규칙은 기본으로 접어 둔다. 펼치면 패널이 길어져서 "방 만들기"가 첫 화면에서 밀려나지 않게.
- 방 코드 입력은 `TextField` code 스타일(고정폭, 대문자).

## 대기실

- 큰 방 코드는 IBM Plex Mono(`room-code`)로. "코드 복사" 옆에 "링크 복사"(`?room=코드` 주소)를 두면 초대가 쉬워진다.
- 플레이어 목록: 번호 · 이름 · 배지(방장/봇 등급) · 오른쪽 "내보내기"(`brand-soft` 바탕 + `brand-strong` 글자).
- 봇 등급 고르기 버튼 5개: `tier-*` 색 알약 + 등급 이름.
- 하단: "봇 추가"(secondary) · "게임 시작"(primary) · "나가기"(텍스트 링크).

## 선 정하기 (칩 던지기 · 룰렛)

- 2명이면 칩 던지기, 3명 이상이면 룰렛. 연출은 그대로 둔다.
- 칩과 룰렛 색을 토큰으로 맞춘다: 와인(`brand`) · 종이(`ground`) · 잉크(`ink`), 가운데 장식은 머스터드(`call`).
- 위에 뜨는 라벨("칩 던지기 · 누가 먼저?")은 `ground` 바탕 종이 쪽지 + −3° 기울임(`CallBanner`와 같은 결).
- 칩·룰렛 칸에는 이름만 쓴다. 숫자·금액은 쓰지 않는다.

## 게임판

```
┌─────────────────────────────────────────────────┐
│ [나가기]   상대 자리 줄 (PlayerChip ×5, 진행 방향 꺾쇠)   [메뉴] │
│                                                 │
│               ( 타원 진행 방향 표시 )               │
│        "낼 카드를 고르세요"  [반시계 방향]           │
│              [덱]     [버린 카드 더미]               │
│              남은 카드 9   [카드 뽑기]               │
│                                                 │
│  [숫자순]                                [빠른 채팅] │
│  ┌──────────── [내 차례 19] ────────────┐          │
│  │            이준서 · 7장             │  ← 손패 칸  │
│  │      [2][6][9][10][10][J][K]        │          │
│  └─────────────────────────────────────┘          │
└─────────────────────────────────────────────────┘
```

- **상대 자리**(`PlayerChip`): `felt-deep` 상자에 이름 · 카드 뒷면 부채 · 장수 · 등급 배지. 차례인 사람은 종이색으로 뒤집히고 "차례", 다음 사람은 점선 + "다음". 장수 숫자는 메이플스토리.
- **가운데 타원**: 진행 방향을 보여주는 얇은 `on-felt` 선(투명도 30%)과 꺾쇠. Q로 방향이 바뀌면 꺾쇠가 반대로 돈다.
- **덱**: 남색(`card-back`) 마름모 무늬 카드. 뒷면 가운데에 ㅎ 스페이드 보조 심볼을 작게.
- **버린 카드 더미**: 마지막 카드가 맨 위, 살짝 어긋나게 쌓인 모양 그대로.
- **손패 칸**: 내 차례면 `call` 머스터드, 남의 차례면 `felt-deep`. 위에 `TurnTimer` 라벨("내 차례 19" / "지수님 차례")과 진행 바. 5초 이하면 라벨·바가 와인색.
- **낼 수 있는 카드 테두리**(`PlayingCard` hint): 빨강 받아치기 · 노랑 막기 · 무지개 조커. 고른 카드는 16px 올라가고 잉크 테두리.
- **그림 카드**: 지금의 클래식 J·Q·K 인물 그림을 그대로 쓴다.
- **빠른 채팅**(`QuickChat`): 웃는 얼굴 버튼 → 이모지 반응 줄 + 문구 10개. 보낸 말은 그 사람 자리 옆 말풍선으로.
- **메뉴**(오른쪽 위): 테마 변경 · 기록·채팅 · 설정. `raised` 바탕 버튼 목록.

## 하이라이트 연출

| 순간 | 연출 | 진동 |
| --- | --- | --- |
| 누가 한 장 남음 | 판이 멈추고 가운데 "{이름}님이 한 장 남았어요" + 3·2·1 | — |
| 원카드 버튼 열림 (2초) | 모두의 화면 가운데 `CallBanner` onecard가 버튼으로 뜸. 가장 먼저 누른 사람이 이김 | 1회 |
| 공격 | `CallBanner` attack, 누적 장수가 커짐 | 2회 |
| 특수 카드 (J·Q·K·7) | 버린 카드 아래 종이 쪽지 라벨("반시계 방향") | — |
| 내 차례 | 손패 칸이 머스터드로, 라벨 "내 차례" | 1회 |
| 5초 남음 | 라벨·바가 와인색 | 1회 |
| 파산 (30장) | 해당 자리 흐려지고 "파산" 배지 | — |
| 승리 | `CallBanner` win + 카드 뒷면이 흩날림 | — |

'애니메이션 줄이기'가 켜져 있으면 배너는 페이드만, 흩날림은 생략.

## 결과 화면

- 승자 이름을 `display-l`로, 그 아래 순위(남은 카드 수 적은 순, 파산은 맨 아래).
- 버튼: "한 판 더"(primary, 같은 방·같은 사람) · "로비로"(secondary) · "친구 더 부르기"(링크 복사). 한 판 끝난 직후가 초대하기 가장 좋은 때다.
