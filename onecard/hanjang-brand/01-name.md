# 이름 — 왜 "한장"인가

## 바꾸는 이유

"온라인 원카드"는 게임 장르의 이름이다. 검색하면 수많은 원카드 앱·사이트와 섞이고, 친구에게 "그거 있잖아, 원카드 사이트"라고 말해도 정확히 어디인지 전해지지 않는다. 사람들이 이름으로 찾아오고 기억하려면 **장르가 아닌 고유한 이름**이 필요하다.

## 한장

- **뜻**: 원카드에서 가장 짜릿한 순간, "마지막 한 장". 게임의 목표(카드를 다 털기)와 하이라이트("원카드!")를 한 단어에 담았다.
- **말맛**: "한 판 하자"처럼 "**한장 하자**"로 바로 쓸 수 있다. 두 글자, 받침이 또렷해 소리 내어 부르기 좋다.
- **설명이 필요 없다**: 카드 게임을 해본 사람은 이름만 듣고 무슨 게임인지 짐작한다.
- **영문 표기**: HANJANG (로마자 표기법 그대로). 영문은 도메인·코드·앱 ID에만 쓰고, 화면에는 한글 "한장"을 쓴다.

### 슬로건

| 쓰임 | 문구 |
| --- | --- |
| 대표 슬로건 | **마지막 한 장까지.** |
| 로비 부제 | 링크 하나로 친구들과 바로 원카드 |
| 초대 메시지 | 한장 하자! 방 코드: K7Q2 |
| 짧은 소개(앱 스토어·SNS) | 설치 없이, 가입 없이. 방 코드 하나로 친구들과 원카드. |

슬로건 끝의 마침표는 지킨다. "끝까지 간다"는 단호함이 마침표에 있다.

## 함께 검토한 후보

| 이름 | 장점 | 탈락 이유 |
| --- | --- | --- |
| **한장** ✔ | 짧고 뜻이 바로 통함, "한장 하자" | — |
| 원카드각 | 친구끼리 말투 그대로 | "각"은 유행어라 금방 낡음 |
| 라스트원 (LAST ONE) | 영어로도 통함 | 한글 화면에서 발음·표기가 어색함 |
| 원콜 | "원카드!" 외침을 떠올림 | 보험·대리운전 등 다른 업종 이름과 겹침 |
| 막판 | 긴장감 | "막장"처럼 부정적으로 읽힐 수 있음 |
| TAK / 탁! | 카드 내려치는 소리 | 비슷한 해외 카드 게임 TAKI가 이미 있음 |

## 출시 전 확인할 것

이 가이드를 만들며 앱스토어에서 "한장"이라는 이름의 카드 게임은 찾지 못했다. 하지만 정식 확인은 아니다. 공개적으로 알리기 전에 아래를 직접 확인한다.

1. **상표**: 특허정보검색서비스 KIPRIS에서 "한장"을 게임·소프트웨어 분류(제9류, 제41류)로 검색.
2. **도메인**: `hanjang` 계열 주소(.com, .kr, .gg, .io 등)가 비어 있는지. 당장은 Render 주소를 `hanjang.onrender.com`처럼 바꾸는 것만으로도 효과가 크다.
3. **SNS 아이디**: 인스타그램·X·유튜브에 `hanjang.game` 같은 아이디가 가능한지.

겹치는 게 있으면 같은 콘셉트를 유지한 채 "한장 하자"나 "한장!"으로 변형한다. 로고 심볼(말풍선 카드)은 이름이 바뀌어도 쓸 수 있지만, 안쪽 ㅎ 스페이드는 "한"에서 온 것이라 이름이 바뀌면 다시 검토한다.
