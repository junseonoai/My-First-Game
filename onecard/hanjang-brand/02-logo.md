# 로고

## 구성

| 파일 | 무엇 | 언제 |
| --- | --- | --- |
| `hanjang-lockup.svg` | 심볼 + 글자 가로 조합 (먹 심볼 + 낙관 도장 + 먹 글자) | **기본.** 로비 상단, 공유 이미지, 발표 자료 |
| `hanjang-lockup-mono.svg` | 가로 조합 단색 (`currentColor`) | 한 가지 색만 쓸 수 있는 자리, 다크 테마 |
| `hanjang-lockup-reverse.svg` | 가로 조합 반전 (한지색 심볼·글자 + 낙관 도장) | `meok` 먹 배경 위 |
| `hanjang-symbol.svg` | 심볼만 (먹 심볼 + 낙관 도장) | 아바타, 로딩 화면 가운데, 정사각형 자리 |
| `hanjang-symbol-mono.svg` | 심볼 단색 (`currentColor`) | 단색 인쇄, 워터마크 |
| `hanjang-wordmark.svg` | "한장" 글자만 (`currentColor`) | 심볼이 이미 근처에 있을 때, 좁은 가로 공간 |
| `hanjang-submark.svg` | 보조 심볼: ㅎ 스페이드 (`currentColor`) | 카드 뒷면, 빈 화면, 스티커, 24px 이하 |
| `favicon.svg` | 파비콘 (단색 ㅎ 스페이드: 밝은 탭에서는 먹, 어두운 탭에서는 한지색으로 자동 전환) | 브라우저 탭 |
| `hanjang-app-icon.svg` | 앱 아이콘 (먹 바탕 + 한지 말풍선 카드 + 낙관) | 홈 화면, PWA, 프로필 사진 |

## 심볼의 뜻

**말풍선 카드.** 카드 한 장에 말풍선 꼬리가 달려 있다. 마지막 한 장이 "원카드!"라고 외치는 순간이다. 카드는 막 내려놓는 움직임처럼 **−8°** 기울어져 있다.

**ㅎ 스페이드.** 카드 안의 무늬는 "**한**"의 ㅎ이다. 짧은 획과 긴 획은 ㅎ의 위쪽, 그 아래 동그라미 자리에 스페이드가 들어갔다. 한글로 만든 카드 게임이라는 표시다.

**낙관 도장.** 심볼 오른쪽 아래의 붉은 네모는 서화에 찍는 낙관(도장)이다. 안에 흰 ㅎ 스페이드가 들어 있다. 로고에서 빨강은 이 도장뿐이다. 도장은 컬러 로고(`lockup`, `lockup-reverse`, `symbol`, `app-icon`)에만 있고 단색 파일에는 없다. 도장의 위치·크기·기울기(+8°)는 바꾸지 않는다. 32px보다 작게 쓸 때는 도장이 뭉개지므로 단색 심볼이나 보조 심볼을 쓴다.

**보조 심볼.** 말풍선을 빼고 ㅎ 스페이드만 남긴 것. 항상 한 가지 색으로만 쓴다(획과 스페이드를 다른 색으로 나누지 않는다). 파비콘처럼 작은 자리에서는 말풍선 안의 가는 획이 뭉개지기 때문에 보조 심볼이 대신한다.

## 글자(워드마크)

"한장" 글자는 **메이플스토리 Bold**(넥슨) 글꼴의 글자 모양을 그대로 벡터 도형으로 바꾼 것이다. 둥글고 통통한 획이 말풍선 심볼의 둥근 모서리와 같은 결이다. 글꼴이 없는 기기에서도 똑같이 보이니, 로고 자리에 글꼴로 "한장"을 직접 타이핑하지 말고 SVG 파일을 쓴다.

메이플스토리 서체는 넥슨코리아 저작물로, 상업적 사용과 로고(BI/CI) 사용이 허용돼 있다. 글꼴 파일 자체를 수정해서 재배포하는 것만 금지다.

## 색 조합

| 바탕 | 쓰는 파일 |
| --- | --- |
| `ground` 한지, `raised` | `hanjang-lockup.svg` (먹 심볼 + 먹 글자) |
| `meok` 먹 (로비 패널 밖) | `hanjang-lockup-reverse.svg` (한지색 심볼·글자) |
| `felt` 초록 (게임판) | `hanjang-lockup-mono.svg`에 `color: var(--on-felt)` |
| `brand` 쪽빛 | `-mono` 파일에 `color: var(--on-brand)` (라이트에서 한지색) |
| 다크 `ground` | `hanjang-lockup-mono.svg`에 `color: var(--ink)` 또는 심볼만 컬러로 |
| 사진·복잡한 이미지 위 | 쓰지 않음. 단색 면을 깔고 그 위에 |

보조 심볼 색: `ink`(먹), `brand`(쪽빛), `on-felt`·`on-meok`(한지색) 중 하나. 놋쇠는 한지 바탕 대비가 부족하고, 낙관 빨강은 도장 전용이라 로고·보조 심볼 색으로 쓰지 않는다. 카드 뒷면에서는 남색 위 한지색.

## 여백과 최소 크기

- **여백**: 로고 주변에 심볼 높이의 1/4만큼은 아무것도 두지 않는다.
- **최소 크기**: 가로 조합 높이 28px / 심볼 32px / 그보다 작으면 보조 심볼(16px까지).

## 하지 말 것

1. 늘이거나 눌러서 비율 바꾸기
2. 심볼의 기울기를 바꾸거나 똑바로 세우기, 말풍선 꼬리 방향 뒤집기
3. 그림자, 외곽선, 그라데이션, 3D 효과 넣기
4. 심볼과 글자의 위치·간격 바꾸기 (위아래 배치가 필요하면 새로 만들어 이 가이드에 추가)
5. 보조 심볼을 두 가지 색으로 칠하기, 말풍선 심볼을 와인·빨강으로 칠하기(빨강은 낙관 도장에만)
6. 다른 글꼴로 "한장"을 쳐서 워드마크 대신 쓰기
7. "♥원카드♠"처럼 텍스트 이모지를 로고 옆에 붙이기

## 파비콘·앱 아이콘 만들기

- **파비콘**: `favicon.svg`를 그대로 사이트 루트에 두고 `<link rel="icon" href="/favicon.svg" type="image/svg+xml">`. 오래된 브라우저용으로 32px PNG도 같이 내보낸다.
- **앱 아이콘(PWA·홈 화면)**: `hanjang-app-icon.svg`를 180·192·512px PNG로 내보낸다. OS가 모서리를 잘라주는 곳에 넣을 때는 바탕 사각형의 `rx="112"`를 `0`으로 바꿔 내보낸다.
