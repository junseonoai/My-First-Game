# 작업: "온라인 원카드" → "한장" 리브랜딩

> 위치 안내: 게임 프로젝트는 저장소의 `onecard/` 폴더다(서버 `onecard/server.js`, 화면 `onecard/public/`). 이 문서에서 `hanjang-brand/...`는 `onecard/hanjang-brand/...`를 뜻한다. 작업은 `claude/onecard-game` 브랜치 기준으로 한다.

hanjang-brand/ 폴더에 브랜드 가이드가 있다. 이 가이드는 게임 화면 스크린샷 몇 장만 보고 만든 것이라,
게임의 실제 작동 방식과 다르게 적힌 부분이 있을 수 있다. 아래 규칙을 반드시 지켜라.

## 1. 무엇이 우선인가 (충돌하면 위가 이긴다)

1. **현재 게임 코드의 실제 동작**: 규칙, 흐름, 기능, 화면 구성, 문구의 의미
2. **사용자가 확정한 결정** (아래 3번 목록)
3. **브랜드 가이드의 시각 규칙**: 색 변수, 모서리, 그림자, 글꼴, 로고
4. **브랜드 가이드의 그 밖의 내용**: 문구 제안, 연출, 화면 구성 제안. 참고만 하고 그대로 적용하지 않는다.

가이드가 실제 게임과 다르면, 가이드가 틀린 것이다. 게임 쪽을 바꾸지 말고 보고한다.

## 2. 절대 하지 않는 것

- 게임 규칙, 서버 로직, 턴 처리, 점수/순위, 봇 AI, 소켓 이벤트를 바꾸지 않는다.
- 기능을 추가하거나 빼지 않는다. 가이드에 "추가 권장"이라고 적힌 것도 포함한다 (예: 링크 복사 버튼, PWA).
- 화면의 배치와 흐름(어떤 화면이 언제 뜨는지, 버튼 순서, 모달 순서)을 바꾸지 않는다.
- 문구의 의미를 바꾸지 않는다. 바꿀 수 있는 문구는 3번 목록에 있는 것뿐이다.
- 연출의 타이밍과 조건(몇 초, 언제 뜨는지)을 가이드에 맞추려고 바꾸지 않는다.
- 메이플스토리 폰트 파일을 수정하지 않는다.

## 3. 사용자가 확정한 결정 (그대로 적용)

- 이름: "한장". 탭 제목은 "한장: 친구들과 바로 원카드", 로비 부제는 "링크 하나로 친구들과 바로 원카드", 슬로건은 "마지막 한 장까지."
- 로비 제목 "♥원카드♠"는 로고 이미지 hanjang-brand/assets/Logos/hanjang-lockup.svg로 교체한다.
- 로고: 말풍선 카드 안에 ㅎ 스페이드가 든 심볼, 메이플스토리 Bold 워드마크.
- 파비콘: favicon.svg (말풍선 없는 ㅎ 스페이드, 단색. 밝은 탭에서는 먹, 어두운 탭에서는 한지색으로 저절로 바뀐다)
- 스타일: 둥근 모서리(--radius-md, --radius-lg)와 부드러운 그림자(--shadow-card, --shadow-lift).
  지금의 각진 굵은 검정 테두리와 딱딱한 오프셋 그림자는 없앤다.
- 글꼴: 제목과 큰 숫자(장수, 타이머 숫자, 배너)는 메이플스토리 Bold(--font-display),
  본문은 Noto Sans KR(--font-sans), 방 코드는 IBM Plex Mono(--font-mono). 지금의 세리프 숫자는 없앤다.
- 색: **2026-11-08에 바뀜.** 예전 결정("지금 게임 색 조합 유지: 와인·머스터드")은 폐기됐다.
  새 색은 "먹을 탄 오방색"이다: 먹(배경·로고), 한지(패널), 쪽빛(주 버튼), 놋쇠(내 차례), 낙관 빨강(공격·경고, 아주 조금).
  적용 방법은 아래 10번을 따른다.
- 테이블 색 5종(초록, 남색, 와인, 나무, 차콜)은 유지한다. 고른 색은 --felt 변수에 넣는다. 기본 테이블은 초록 그대로다.
- 칩 던지기와 룰렛 연출은 그대로 유지한다. 색만 토큰으로 맞춘다.
- "내 차례"일 때 손패 칸이 콜 색으로 바뀌는 구조를 유지한다 (--call 색, 이제 놋쇠 #b8923f).
- 낼 수 있는 카드 테두리의 의미는 지금 규칙 그대로다: 빨강 받아치기, 노랑 막기, 무지개 조커.
  선택한 카드는 이 색들과 겹치지 않게 표시한다. (빨강은 이제 낙관 빨강, 노랑은 놋쇠. 의미는 같다.)
- 캐릭터: 갓 쓰고 남색 도포를 입은 검은 스페이드 머리 캐릭터(hanjang-brand/assets/Character/). 머리는 항상 먹색. 이름은 미정.

## 4. 확정되지 않은 것 (적용하지 말고 먼저 물어볼 것)

- 그림 카드(J·Q·K)의 클래식 인물 이미지를 유지할지
- 카드 뒷면 가운데에 ㅎ 스페이드 마크를 넣을지 (남색 무늬는 유지)
- 다크 테마를 새로 만들지 (지금 게임에 다크 테마가 없다면 만들지 않는다)
- 캐릭터 그림을 게임 화면(로비 옆, 로딩, 결과 화면)에 넣을지와 어디에 넣을지. 10번 작업에서는 넣지 않는다.
- 빠른 채팅의 지금 이모지(emo-0~9)를 바꿀지. 캐릭터 이모지 세트는 아직 없으니 그대로 둔다.

## 5. 가이드에서 검증되지 않은 내용 (실제 코드와 대조할 것)

가이드 작성자는 아래 화면이나 동작을 직접 보지 못했다. 이 부분의 가이드 내용은 추측이다.

- 결과/승리 화면의 구성, 버튼, 연출 (예: "카드 흩날림", "한 판 더" 버튼)
- 파산·재접속·퇴장 때의 표시와 문구
- 원카드 진행 화면의 실제 문구와 카운트다운 표시 방식
- 공격 배너, 특수 카드 라벨의 실제 문구와 모양
- 진동 패턴, 소리, 애니메이션 시간
- 03-voice.md의 "게임 중 문구" 표 전체 (상황별 문구 제안)
- 오류 문구 (없는 방, 꽉 찬 방, 이미 시작한 방), 닉네임 글자 수 제한, 최대 인원
- 04-game-screens.md의 와이어프레임과 "권장" 항목

이 부분에서 코드와 가이드가 다르면 **코드를 따르고** 차이를 보고한다.
가이드 문구가 더 낫다고 판단돼도 바꾸지 말고 제안 목록에만 적는다.

### 주의: `--red` 별칭 (2026-11-08 코드 기준 관찰, 다시 확인할 것)

지금 `onecard/public/style.css`는 `--red: var(--brand)`, `--red-dark: var(--brand-strong)`로 와인 하나를 **주 버튼과 경고에 같이** 쓴다.
`--brand`가 쪽빛으로 바뀌므로 `tokens.css`만 덮어쓰면 공격·경고까지 남색이 된다. 이렇게 나눈다.

1. `--red: var(--seal)`, `--red-dark: var(--seal-strong)`로 바꾼다. 그러면 공격·경고는 낙관 빨강이 된다.
2. 주 버튼만 쪽빛으로 바꾼다. 예: `.btn.primary`의 바탕 `var(--red)` → `var(--brand)`, 글자 `var(--on-brand)`. 눌림 상태(`#home .btn.primary:active` 등)의 `var(--brand)`는 그대로 둔다.
3. `--brand`를 직접 쓰는 나머지 자리(J 건너뜀 표시 `.skip-mark`, 룰렛 바깥 테두리 등)는 하나씩 보고하고, 경고 성격이면 `--seal`, 장식이면 그대로 둔다. 애매하면 묻는다.
4. 게임이 따로 정의한 색: `--brand-light`(와인 빗금의 밝은 줄)는 `#c9564f`로, `--call-deep`(머스터드 위 진한 선)은 `#6b5219`로 바꾼다.
5. `index.html` 안에 직접 박힌 #933231·#ccac52·#f3da87(인라인 SVG 등)은 변수나 새 값으로 바꾼다.

### `tokens.css` 합치기

`onecard/public/tokens.css`를 `hanjang-brand/tokens.css`로 **통째로 덮어쓰지 말고** 값을 합친다. 게임 쪽에 따로 추가한 변수와 `[data-table=...]` 규칙이 있을 수 있다.
- 바뀐 값: `--brand*`, `--on-brand`, `--call*`, `--hint-counter`, `--hint-block`, 다크 테마의 `--ground` `--raised` `--sunken` `--line*`
- 새 변수: `--seal`, `--on-seal`, `--seal-soft`, `--seal-strong`, `--meok`, `--meok-deep`, `--meok-wash`, `--on-meok`
- 조커 힌트 무지개 테두리(있다면)는 적·황·백·청 순서: #c0443f, #b8923f, #f0ead8, #5a6fb0

### 칩·룰렛

연출(움직임, 시간, 규칙)은 바꾸지 않는다. 색 변수만 따라 바뀌는 것은 괜찮다(빨강 칸은 낙관 빨강, 노랑은 놋쇠).
칩·룰렛에 이름 말고 숫자·금액을 넣지 않는다는 규칙도 그대로다.

### 로고 파일

`onecard/public/favicon.svg`, `logo.svg`(= `hanjang-lockup.svg`), `submark.svg`를 `hanjang-brand/assets/Logos/`의 새 파일로 바꾼다.
로비 패널이 한지색이면 `hanjang-lockup.svg`, 먹 배경 위에 바로 놓이면 `hanjang-lockup-reverse.svg`를 쓴다.
`og.png`는 새 색으로 다시 만들어야 하지만, 만드는 방식이 정해지지 않았으니 보고만 한다.
