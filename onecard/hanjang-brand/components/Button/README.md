# Button

행동을 시작하는 버튼. 글자는 동사로 끝나게, 짧게("방 만들기", "참가", "다시 하기").

- **primary** (`brand` 채움): 화면의 주인공 행동. 화면당 하나만. 로비에서는 "방 만들기", 결과 화면에서는 "한 판 더".
- **secondary** (`raised` + `line-strong` 테두리): 그 다음 행동("코드로 참가", "튜토리얼").
- **ghost**: 덜 중요한 행동, 닫기·취소.
- **call** (`call` 채움): 오직 "원카드!" 외치기 버튼. 다른 데 쓰면 외침의 힘이 빠진다.
- 크기: `lg` 52px(모바일 주 버튼), `md` 44px(기본, 터치 최소 높이), `sm` 34px(칩 안 보조 버튼만).
- 비활성은 숨기지 말고 `disabled` + 이유를 주변 글자로("2명 이상 모이면 시작할 수 있어요").
- 사용하는 쪽이 넣는 것: `variant`, `size`, `icon`(선택, 24px 아이콘), `children`(라벨), 나머지 `button` 속성.
