# CallBanner

게임의 하이라이트 순간에 테이블 가운데 뜨는 배너. 살짝 기울어진(−3°) 스티커 느낌.

- `onecard`: `call` 옐로, "원카드!". 한장 브랜드에서 가장 중요한 순간.
- `attack`: `seal` 낙관 빨강, "공격 +N". 누적 장수를 크게.
- `win`: `felt` 그린 위 `call` 글자, "승리!".
- 1.2초 동안 커지며 나타났다 사라진다. '애니메이션 줄이기'가 켜져 있으면 페이드만.
- 한 번에 하나만. 겹치면 나중 것이 앞의 것을 대체한다.
- 사용하는 쪽이 넣는 것: `kind`, `title`(기본 문구 덮어쓰기), `detail`, `amount`(attack).
