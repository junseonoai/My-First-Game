# QuickChat

게임 중 한 번 눌러 보내는 빠른 채팅. 2열 버튼판으로, 웃는 얼굴 버튼을 누르면 손패 칸 위에 뜬다.

- 문구는 한장 말투(짧게, ~요)로: "빨리 내요!", "잘했어요", "아 안 돼!", "봐주세요", "원카드 조심!", "공격 간다!", "운이 좋네요", "한 판 더?", "ㅋㅋㅋㅋ", "안녕하세요".
- 놀리는 말은 되지만 깎아내리는 말은 넣지 않는다(말투 섹션 참고).
- 버튼판 위의 이모지 반응 줄은 시스템 이모지 대신 한장 이모지 10종(`assets/Emoji/`)을 쓴다: 신남·빵터짐·여유·엉엉·부글부글·헉·최고·원카드!·불타오름·망했다. 그 밖의 UI 글자에는 이모지를 쓰지 않는다.
- 보낸 말은 보낸 사람 자리(PlayerChip) 옆에 말풍선으로 2초간 뜬다. 말풍선 모양은 로고 심볼의 꼬리와 같은 방향.
- 사용하는 쪽이 넣는 것: `phrases`(선택, 기본 10개), `onSend(text)`.
