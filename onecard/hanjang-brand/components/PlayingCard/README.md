# PlayingCard

한장의 카드 한 장. 앞면은 다크 테마에서도 하얗고(`card-face`), 뒷면은 지금 게임의 남색(`card-back`) 마름모 무늬 위에 종이색 ㅎ 스페이드 보조 심볼.

- 무늬 색: ♥♦는 `suit-red`, ♠♣는 `suit-black`. 색만으로 구분하지 않도록 무늬 모양을 모서리와 가운데 두 번 보여준다.
- 상태: `playable`(낼 수 있음, 호버 시 6px 올라감) · `selected`(16px 올라가고 잉크 테두리) · `disabled`(채도와 불투명도를 낮춤) · 기본.
- 낼 수 있는 이유 테두리(`hint`, 지금 게임 규칙 그대로): `counter` 빨강 = 받아치기 · `block` 노랑 = 막기(같은 무늬 3) · `joker` 무지개 = 조커. 선택(`selected`)은 이 색들과 헷갈리지 않게 잉크색 테두리로만 표시한다.
- `attack`: 2·A·조커처럼 공격 카드에 "공격" 꼬리표. 숫자 옆에 붙여 색약 사용자도 읽게 한다.
- 크기: `md` 72×100(손패, 버린 더미), `sm` 48×67(상대 손패 표시, 기록).
- 손패를 펼칠 때 카드 간 겹침은 카드 너비의 40%(md 기준 −28px)까지. 그 이상 겹치면 숫자가 가려진다.
- 클릭 가능하게 쓰면 `onClick`을 넘긴다 — 그러면 `role=button`, `tabIndex`, `aria-pressed`가 붙는다.
- 그림 카드(J·Q·K)는 지금 게임의 클래식 인물 그림을 그대로 쓴다. 이 컴포넌트는 숫자 카드 모양의 기준이다.
- 사용하는 쪽이 넣는 것: `hint`, `rank`("A","2"…"10","J","Q","K", 조커는 "color"/"mono"), `suit`, `faceDown`, `state`, `attack`, `size`, `onClick`.
