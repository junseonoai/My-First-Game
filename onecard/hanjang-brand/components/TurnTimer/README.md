# TurnTimer

내 손패 칸 위에 걸리는 차례 표시 + 30초 진행 바. 지금 게임의 "내 차례 8" 라벨 구조를 그대로 살렸다.

- 내 차례: `call` 머스터드 알약에 "내 차례" + 남은 초(메이플스토리 숫자), 뒤의 바는 `call-soft`가 줄어든다. 이때 손패 칸 전체도 `call`로 바뀐다.
- 5초 이하: 알약과 바가 `brand` 와인 레드로. '진동' 설정이 켜져 있으면 한 번 진동.
- 남의 차례(`waiting`): `felt-deep` 알약에 "지수님 차례", 바는 비운다. 손패 칸은 `felt-deep`.
- 0초면 자동으로 1장 뽑힌다. 처음 한 번은 "시간이 다 돼서 한 장 뽑았어요" 토스트.
- 사용하는 쪽이 넣는 것: `seconds`, `total`(기본 30), `label`(기본 "내 차례"), `waiting`.
