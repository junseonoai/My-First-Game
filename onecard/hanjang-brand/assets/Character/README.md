# Character

- `hanjang-character-keyart.jpg` — 한장 캐릭터 키 비주얼(1600×1195). 갓 쓰고 남색 도포를 입은 검은 스페이드 머리 캐릭터가 한지 위 수묵 번짐 속에 서 있다. 로비 첫 화면, 공유 이미지(og.png), 로딩·연결 끊김·결과 화면에 쓴다.

색과 모양은 바꾸지 않는다(머리는 항상 먹색). 이모지용 표정 세트는 같은 캐릭터로 따로 만든다(아직 없음).

출처: 생성형 AI(Gemini) 초안. 정식 출시 전에 이용약관의 상업적 사용 조건을 확인하고, 가능하면 일러스트레이터 원본으로 바꾼다.
