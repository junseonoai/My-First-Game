# Icons

24×24, `currentColor`. 선 아이콘은 1.75px 둥근 선, 무늬 아이콘은 채움. 버튼 안에서는 20px, 단독으로는 24px.

- `suit-heart.svg`, `suit-diamond.svg` — 붉은 무늬(카드 위에서는 `suit-red`).
- `suit-spade.svg`, `suit-club.svg` — 검은 무늬(`suit-black`).
- `attack.svg` — 번개. 공격 카드, 공격 받음 알림.
- `defend.svg` — 방패. 방어 성공.
- `draw-card.svg` — 카드 + 더하기. 카드 뽑기 버튼.
- `timer.svg` — 턴 타이머.
- `players.svg` — 인원 수, 대기실.
- `copy.svg` — 방 코드·링크 복사.
- `crown.svg` — 승자, 방장.
- `reconnect.svg` — 재접속 중.
