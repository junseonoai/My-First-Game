# Emoji

게임 중 빠른 채팅 판 위쪽 이모지 반응 줄에 쓰는 한장 전용 이모지 10종. 캐릭터는 보조 심볼(ㅎ 스페이드)에 표정을 넣은 것이다. 시스템 이모지(😂 등)는 기기마다 모양이 달라서 이 세트로 바꾼다.

색은 고정(와인 #933231 몸통, 잉크 #1e1a15 모자, 종이 #f0ead8 얼굴, 머스터드 #ccac52·청록 #7fb5ae 소품). `<img>`로 바로 쓴다. 반응 줄에서는 28~32px, 자리 옆 말풍선에서는 40px.

| 파일 | 이름 | 대신하는 기존 이모지 | 쓰는 때 |
| --- | --- | --- | --- |
| `hj-happy.svg` | 신남 | 😀 | 기분 좋을 때, 인사 |
| `hj-lol.svg` | 빵터짐 | 😂 | 웃길 때 |
| `hj-cool.svg` | 여유 | 😎 | 잘 풀릴 때, 자랑 |
| `hj-cry.svg` | 엉엉 | 😭 | 공격 맞았을 때 |
| `hj-angry.svg` | 부글부글 | 😡 | 막혔을 때 |
| `hj-shock.svg` | 헉 | 😱 | 예상 못 한 공격·조커 |
| `hj-thumb.svg` | 최고 | 👍 | 칭찬 |
| `hj-onecard.svg` | 원카드! | 👏 | 한 장 남았을 때, 도발 |
| `hj-fire.svg` | 불타오름 | 🔥 | 연속 공격, 승부욕 |
| `hj-ko.svg` | 망했다 | 💀 | 파산, 크게 졌을 때 (회색 몸통) |

규칙: 이모지를 늘릴 때도 같은 몸통·모자·선 굵기(4px)를 지킨다. 누군가를 깎아내리는 표정(조롱, 손가락질)은 만들지 않는다.
