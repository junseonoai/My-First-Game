# 고요골 — 기획과 구조

이 문서 하나로 게임의 방향, 지금까지 만든 것, 다음에 만들 것을 알 수 있게 썼다.
작업을 이어받는 사람은 이 문서를 먼저 읽고, 바뀐 결정이 생기면 이 문서를 고친다.

대표 이미지: [concept/keyart.jpg](concept/keyart.jpg) (분위기와 주인공 디자인의 기준)

---

## 1. 한 줄 소개

기억을 잃은 방랑자가 지도에 없는 골짜기 "고요골"에서 채집하고, 흐려진 생물을 달래고,
잠든 기억의 돌을 깨워 가며 마을을 하나씩 개척해 나가는 3인칭 생활형 액션 RPG.

### 어디서 온 느낌인가

- 작은 세계를 통째로 돌아다니며 주변의 거의 모든 것과 상호작용하고, 반복 행동으로 성장하는
  옛 모바일 생활형 RPG의 **느낌**.
- 90년대 말 3D 모험 게임의 로우폴리 분위기.

**가져오는 것은 느낌과 방식뿐이다.** 다른 게임의 이름, 캐릭터, 맵, 문양, 화면 디자인은 쓰지 않는다.
(이미지 생성 과정에서 특정 게임의 요정·문장이 섞여 나온 적이 있어 걸러 냈다.)

## 3. 세계와 이야기

### 3.1 고요골

높은 산줄기에 둘러싸여 바깥 지도에는 빈칸으로 남은 골짜기. 오래전 누군가 살았던 흔적
(돌탑, 이끼 낀 물레방아, 끊어진 돌다리)이 있지만 누가 살았는지 아는 사람이 없다.
바깥 기록에서도, 사람들의 기억에서도 지워져 있다.

문화는 어느 나라라고 할 수 없는 가상의 것으로, 돌탑·장승풍 기둥과 물레방아·풍차가 함께 있다.
옛 사람들의 것은 돌과 이끼, 개척민의 것은 새 나무와 천막으로 구분한다.

### 3.2 기억의 돌

- 골짜기 곳곳에 빛을 잃은 선돌이 서 있다. 골짜기가 잊히면서 돌도 잠들었다.
- 돌이 잠든 지역은 안개가 끼고, 생물들이 **흐려진다**.
- 그 지역에서 난 재료를 돌에 바치면 깨어난다.
- 깨어나면 돌아오는 것: ① 골짜기의 옛 모습(안개가 걷히고 다음 지역 길이 드러남)
  ② 주인공의 기억 한 조각(회상) ③ 새 능력이나 제작법(아직 미구현).

### 3.3 흐려진 생물

원래는 순한 숲의 생물. 잊히면서 윤곽이 뿌옇게 번지고 사나워졌다.
쓰러뜨리면 죽지 않고 제 모습으로 돌아가 달아나며 **안개 조각**을 남긴다.
돌이 깨어난 지역에서는 순한 모습으로 돌아다닌다.

### 3.4 주인공

- 이름도 과거도 기억나지 않는다. 숲 가장자리에서 눈을 뜬다.
- 외모: 잿빛 은발이 끝으로 갈수록 청록빛, 등에 **끊어진 원**이 은실로 수놓인 짙은 남색 망토,
  한쪽 팔의 붕대 천, 허리의 돌 꾸러미, 끈 샌들, 끝에 **돌 등불**이 달린 지팡이.
- 등불은 기억의 돌과 같은 빛을 낸다. 돌을 깨울 때마다 조금씩 밝아진다.
- 처음 온 곳인데 길이 낯설지 않고, 도구를 쥐면 쓰는 법이 떠오른다(숙련도 설명).
- 끊어진 원 문양은 옛 돌탑에도 새겨져 있다(기록꾼 한결의 대사).
- **정체는 아직 정하지 않았다.** 회상은 어느 쪽으로도 이어지게 풍경과 목소리만 보여 준다.

### 3.5 첫돌마을 주민

| 주민 | 역할 | 성격 |
|---|---|---|
| 촌장 바우 할멈 | 길잡이 | 개척단을 이끌고 온 사람. 주인공에게 오두막을 내준다 |
| 목수 도담 | 벌목·도구 | 말수 적고 손이 큰 사람 |
| 약초꾼 소리 | 채집·물약 | 호기심 많고 흐려진 생물을 불쌍히 여긴다. 주인공을 처음 발견한다 |
| 잡화상 너울 | 상점 | 바깥과 오가는 유일한 행상 |
| 기록꾼 한결 | 기억의 돌 연구 | 옛 글자를 읽으려는 학자 |

### 3.6 지역과 개척

돌을 깨워 지역이 열리면 그곳에 새 마을을 세운다. 마을이 생길 때마다 첫돌마을 주민 일부가
옮겨 가고 바깥에서 새 개척민이 들어온다.

| 순서 | 지역 | 세워지는 마을 | 새로 생기는 것 | 상태 |
|---|---|---|---|---|
| 1 | 들머리 숲 | 첫돌마을 (처음부터 있음) | 벌목, 채집, 도구 | **구현됨** |
| 2 | 거울못 | 나루 마을 | 낚시, 배 | 다음 차례 |
| 3 | 바람고개 | 고갯마루 마을 | 채광, 대장간 | |
| 4 | 옛 마을터 | 옛터 위에 다시 세운 마을 | 옛 기술, 기록 | |
| 5 | 골짜기 가장 깊은 곳 | 없음 | 마지막 돌과 결말 | |

### 3.7 결말 (확정: 1안)

- 마지막 돌이 품은 기억은 주인공 개인의 과거가 아니라 **골짜기의 진짜 이름**이다.
  이름이 잊히면서 골짜기 전체가 세상에서 지워졌다.
- 주인공은 그 이름을 마지막까지 기억하고 있던 사람이고, 이름을 소리 내어 부르는 순간 모든 안개가 걷힌다.
- 주인공 자신의 옛 이름은 끝내 돌아오지 않는다. 대신 그동안 세운 마을 사람들이 불러 준 이름이
  진짜 이름이 된다.
- 엔딩 뒤에도 계속 플레이할 수 있게, 산 너머로 가는 길이 열리고 바깥 사람들이 찾아오기 시작한다.

### 3.8 아직 정하지 않은 것

- 주인공의 정체, 옛 사람들이 왜 사라졌는지, 골짜기가 왜 잊혔는지
- "고요골"이 잊힌 뒤에 붙은 이름이라면, 되찾을 진짜 이름은 무엇인지
- 주인공 이름을 플레이어가 짓게 할지, 주민들이 지어 줄지

## 4. 아트 방향

- 대표 이미지의 분위기: 해질녘, 깊은 그림자, 차분한 흙빛과 청록·남색, 은은한 빛.
- 돌이 잠든 지역은 안개 낀 회청색, 깨어난 지역은 안개가 걷히고 조금 밝아진다
  (`world.js` 의 `setMood`).
- 색은 `core.js` 의 `G.PAL` 한곳에 모여 있다.
- 모델은 `models.js` 에서 기본 도형을 합쳐 만든다. 주인공은 뒷모습이 가장 많이 보이므로
  등(망토 문양, 머리 색, 등불)이 상징이 되게 한다.

## 5. 지금 구현된 것 (1장: 들머리 숲)

- 제목 화면, 처음부터/이어하기, 자동 저장(`localStorage`)
- 3인칭 이동, 카메라 자동 추적·드래그 회전·줌, 건물에 가려지지 않게 당겨지는 카메라,
  시야를 가리는 나무는 줄기만 보이기
- PC(키보드·마우스)와 휴대폰(가상 조이스틱·버튼) 조작
- 행동 버튼의 상황별 전환, 주민 머리 위 `!`/`?` 표시
- 벌목(도끼 필요, 다시 자람), 산열매·약초 채집(다시 열림)
- 흐려진 생물 8마리: 배회 → 추격 → 움츠렸다 달려들기. 달래면 안개 조각을 주고 달아났다가 다시 나타남
- 숙련도 4종과 그 효과, 체력, 열매즙, 오두막에서 쉬기, 쓰러짐
- 퀘스트 5개: 낯선 골짜기 → 도담의 일손 / 소리의 열매즙 → 흐려진 것들 → 잠든 돌
- 기억의 돌 깨우기: 화면 번쩍임, 회상, 안개 걷힘, 꽃 피어남, 생물이 제 모습을 찾음, 북쪽 길 열림
- 잡화점(사기·팔기), 반복 의뢰 게시판

## 6. 코드 구조

빌드 도구 없이 `<script>` 를 순서대로 불러오는 방식이다. 모든 파일이 전역 `G` 에 자기 영역을 붙인다.
모듈(`import`)을 쓰지 않는 이유는 `index.html` 을 더블클릭해 `file://` 로 열어도 실행되게 하기 위해서다.

| 파일 | 영역 | 하는 일 |
|---|---|---|
| `js/core.js` | `G`, `G.PAL`, `G.bus` | 유틸, 색 팔레트, 이벤트 버스 |
| `js/data.js` | `G.DATA` | **내용 전부**: 아이템, 숙련도, 주민과 대사, 퀘스트, 상점, 의뢰, 회상 |
| `js/models.js` | `G.models`, `G.geo` | 도형을 합쳐 만드는 모델 |
| `js/world.js` | `G.world` | 지형, 빛과 하늘, 배치, 충돌, 자원, 분위기 전환 |
| `js/systems.js` | `G.sys` | 가방, 돈, 숙련도, 퀘스트 진행, 의뢰, 저장 |
| `js/ui.js` | `G.ui` | HUD, 알림, 대화, 창, 회상, 제목 화면 |
| `js/input.js` | `G.input` | 키보드·마우스·터치를 하나의 입력 상태로 |
| `js/player.js` | `G.player`, `G.cam` | 주인공 상태와 동작, 카메라 |
| `js/entities.js` | `G.ent` | 주민, 생물 AI, 행동 버튼 대상 판단 |
| `js/main.js` | `G.debug` | 시작, 게임 루프, 시험용 손잡이 |
| `vendor/three.min.js` | `THREE` | three.js r160 (같이 넣어 두어 인터넷 없이도 실행) |

### 자주 할 일

- **아이템 추가**: `data.js` 의 `items` 에 한 줄. 팔 수 있으면 `sell`, 쓸 수 있으면 `use`.
- **퀘스트 추가**: `data.js` 의 `quests` 에 항목 추가. 단계 종류는 `talk`, `collect`, `calm`, `offer`.
  새 종류가 필요하면 `systems.js` 의 `S.talk` / `S.onCalm` 근처에 처리를 더하고 `S.tracker` 에 표시 글을 더한다.
- **주민 추가**: `data.js` 의 `npcs` 에 항목 추가(위치, 생김새, 평소 대사). 나머지는 자동.
- **수치 조정**: 숙련도 효과는 `systems.js` 의 `S.maxHp`, `S.damage`, `S.chopsNeeded`, `S.bonusChance`.
  이동·공격 속도는 `player.js` 맨 위 상수. 생물의 체력·속도는 `entities.js` 의 `updateCreature`.
- **새 모델**: `models.js` 에서 `Builder` 로 도형을 쌓는다. 많이 깔리는 것은 `world.js` 의 `inst()` 로 인스턴싱.

### 조심할 것

- 월드 배치는 고정 시드 난수(`G.makeRng`)로 만든다. 배치 순서를 바꾸면 나무 위치가 전부 달라진다.
- `inst(geo, max)` 의 `max` 를 넘겨 넣으면 화면에 검은 쐐기가 나타난다. 넉넉히 잡는다.
- 저장 형식을 바꾸면 `G.SAVE_KEY` 의 버전 숫자와 `S.load` 의 `v` 검사를 함께 올린다.
- 대화·창이 열려 있으면 `G.ui.busy` 가 참이고 주인공과 생물의 공격이 멈춘다.

## 7. 시험

```
node goyogol/tools/smoke.js
```

1장을 처음부터 끝까지 자동으로 진행하고 저장·이어하기·쓰러짐까지 확인한다.
화면을 그리지 않고 `G.debug.step(n)` 으로 게임만 빠르게 돌린다.
기능을 더하거나 고치면 이 시험을 먼저 돌리고, 새 기능의 확인 항목을 더한다.

브라우저 콘솔에서 쓸 수 있는 것: `G.debug.give('wood', 10)`, `G.debug.tp(x, z)`, `G.debug.step(60)`.

화면 확인은 실제 브라우저에서 한다. GPU 없는 서버에서는 초당 몇 프레임밖에 안 나오므로
시간에 기대는 자동 조작(키를 누르고 기다리기)은 믿을 수 없다.

## 8. 다음에 할 일 (우선순위 순)

1. **직접 플레이해 보고 손맛 다듬기** — 이동 속도, 카메라 거리, 전투 난이도, 숙련도 오르는 속도.
   실제 휴대폰에서의 성능(삼각형 약 20만 개, 그림자 포함)도 확인. 느리면 `world.js` 의 나무 수와
   그림자 해상도부터 줄인다.
2. **소리** — 발소리, 도끼질, 타격, 돌이 깨어날 때의 소리, 잔잔한 배경음. 지금은 소리가 전혀 없다.
3. **2지역 거울못** — 지형을 지역 단위로 나누고(`world.js` 의 `hgt` 와 `build`), 호수와 낚시,
   나루 마을 세우기(재료를 모아 건물을 올리는 "개척" 시스템의 첫 구현), 두 번째 돌과 회상.
4. **돌이 깨어날 때 얻는 능력·제작법** — 3.2의 ③. 도구 제작(도담)과 묶으면 좋다.
5. **주인공 모델 다듬기** — 머리 모양이 뒤에서 보면 돌덩이처럼 보인다. 도끼질할 때도 지팡이를 휘두른다
   (도끼 모델과 동작이 없다). 망토 자락 흔들림.
6. **주민과의 관계** — 선물, 호감도, 동료로 데리고 사냥(원래 느낌의 한 축이지만 첫 버전에서는 뺐다).
7. **낮과 밤**, 날씨, 마을의 일과.
8. 미정 사항(3.8)을 함께 정하기.

## 9. 알려진 한계

- 깨어난 뒤의 1지역에는 흐려진 생물이 없어 안개 조각을 더 얻을 수 없다(의뢰 게시판의 안개 조각 의뢰는
  그때 끝낼 수 없다). 2지역이 생기면 해결된다.
- 충돌은 원 모양뿐이라 집 모서리에서 조금 어색하다.
- 강 건너편과 다리는 풍경일 뿐 건널 수 없다.
- 북쪽 길 끝(거울못 방향)은 안내 문구만 나오고 막혀 있다.
