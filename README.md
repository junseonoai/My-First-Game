# 풍등 날리기

소원을 담은 풍등을 밤하늘 높이 띄워 보내는 브라우저 게임입니다.

- **움직이기**: 화면을 끌거나 ← → (A / D) 키
- **반딧불**: 모으면 불씨가 다시 살아나요
- **박쥐·나뭇가지**: 부딪히면 불씨가 크게 줄어요
- 불씨가 다 꺼지면 게임이 끝나요. 높이 올라갈수록 빨라집니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 플레이할 수 있어요. 설치할 것은 없습니다.
