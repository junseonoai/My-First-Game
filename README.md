# My First Game

설치 없이 브라우저에서 바로 플레이하는 게임들입니다.

## 고요골 (만드는 중)

기억을 잃은 방랑자가 잊힌 골짜기에서 나무를 베고, 열매를 따고, 흐려진 생물을 달래며
잠든 기억의 돌을 깨워 가는 3D 게임입니다.

- **실행**: `goyogol/index.html` 파일을 브라우저로 엽니다.
- **PC**: 이동 WASD · 행동 Space · 구르기 Shift · 가방 I · 시점 마우스 드래그 · 줌 휠
- **휴대폰**: 화면 왼쪽을 누르고 끌면 이동, 오른쪽을 끌면 시점, 오른쪽 아래 버튼으로 행동·구르기·가방
- 행동 버튼은 가까이 있는 것에 따라 대화·베기·따기·공격으로 바뀝니다.
- 진행 상황은 자동으로 저장됩니다.

기획과 구조는 [goyogol/docs/DESIGN.md](goyogol/docs/DESIGN.md) 에 있습니다.

## 풍등 날리기

소원을 담은 풍등을 밤하늘 높이 띄워 보내는 게임입니다.

- **실행**: `index.html` 파일을 브라우저로 엽니다.
- **움직이기**: 화면을 끌거나 ← → (A / D) 키
- **반딧불**: 모으면 불씨가 다시 살아나요
- **박쥐·나뭇가지**: 부딪히면 불씨가 크게 줄어요
- 불씨가 다 꺼지면 게임이 끝나요. 높이 올라갈수록 빨라집니다.
